## 질문 수정
questions.js를 텍스트 편집기로 열어 원하는 카드의 text를 수정하고 저장한 뒤 브라우저를 새로고침하세요.

- original: 대화 카드 78개. level은 1(가볍게), 2(솔직하게), 3(아슬하게). type은 진실, 미션, 지목, 밸런스 중 하나.
- mission: 미션 카드 40개. level은 1~4, type은 미션.
- 카드는 { ... } 블록을 복사해서 추가하거나 삭제할 수 있습니다. 카드 사이 쉼표를 유지하세요.

- 이전에 JSON을 가져왔다면 저장된 카드가 우선합니다. 화면의 기본 카드 복원 버튼을 눌러 수정한 파일의 카드로 돌아오세요.
